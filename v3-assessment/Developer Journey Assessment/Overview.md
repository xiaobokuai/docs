# Developer Journey Assessment

Definition: Evaluating the performance of open source communities throughout the entire lifecycle of developer attraction, growth, and retention, reflecting the community's ability to cultivate and retain developer talent.

# Assessment Model

The developer journey assessment includes three key stages:

## Developer Attraction

Evaluating the community's ability to attract new developers to join, including the growth of organizational and individual code and non-code contributors.

For detailed metrics, please refer to: [Developer Attraction](./Developer%20Attraction.md)

## Developer Growth

Evaluating the community's ability to cultivate developers from beginners to core contributors, including developer participation tiering and promotion mechanisms.

For detailed metrics, please refer to: [Developer Growth](./Developer%20Growth.md)

## Developer Retention

Evaluating the community's ability to retain core developers, including core developer retention rate, churn rate, and loss rate.

For detailed metrics, please refer to: [Developer Retention](./Developer%20Retention.md)

# Assessment Significance

Developers are the most valuable resource of open source communities. A healthy open source community should possess:
- The ability to continuously attract new developers to join
- Well-established developer growth paths and cultivation mechanisms
- Strong capability to retain core developers

Through developer journey assessment, communities can identify their strengths and weaknesses in developer management and formulate targeted improvement strategies.
